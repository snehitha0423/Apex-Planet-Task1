# Apex Planet Data Analytics Internship – Task 1

## Data Cleaning & Data Preparation

This project is part of the **Apex Planet Data Analytics Internship**.

The objective of Task 1 was to understand the given sales dataset, inspect its structure, identify important variables, clean and prepare the data, and create a data dictionary for further analysis.

---

## Project Objective

The main objectives of this task were:

- Understand the structure of the sales dataset
- Inspect the dataset and its variables
- Identify important data dimensions
- Perform data cleaning and preparation
- Handle data quality issues
- Create a data dictionary
- Prepare a cleaned dataset for further analysis

---

## Dataset

The dataset contains sales-related information that can be used to analyze:

- Customers
- Products
- Categories
- Sales
- Orders
- Cities
- Gender
- Dates
- Pricing information

The cleaned dataset prepared in this task was used as the foundation for the subsequent data analytics tasks.

---

## Task 1 Work

### 1. Data Understanding

The dataset was first inspected to understand:

- Number of records
- Dataset structure
- Column names
- Data types
- Important business variables

### 2. Data Inspection

The dataset was examined to identify:

- Missing values
- Duplicate records
- Incorrect data types
- Inconsistent values
- Important dimensions and measures

### 3. Data Cleaning

The required data cleaning and preparation steps were performed to make the dataset suitable for analysis.

### 4. Data Dictionary

A data dictionary was created to document the important variables in the dataset and improve understanding of the data.

### 5. Final Dataset Preparation

After cleaning and preparation, the final dataset was saved and made ready for exploratory and business analysis.
